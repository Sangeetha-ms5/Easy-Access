# Easy Access – Government Schemes Knowledge-Sharing Website

## 📌 About the Project

**Easy Access** is a knowledge-sharing website designed to help users easily **discover, explore, and understand government schemes**. The platform provides organized information about different schemes along with their **eligibility criteria, benefits, required documents, and application details**.

The main goal of Easy Access is to make government scheme information simple, accessible, and easy to understand for everyone.

## 🎯 Objectives

* Help users discover government schemes in one place.
* Allow users to explore schemes based on their needs.
* Provide clear and simple eligibility criteria.
* Explain scheme benefits and requirements.
* Display required documents for applying.
* Help users understand the application process.
* Reduce the difficulty of finding relevant government schemes.

## ✨ Key Features

### 🔍 Explore Government Schemes

Users can browse and explore different government schemes available across various categories.

### ✅ Eligibility Checking

Users can check the eligibility criteria of a scheme and understand whether they meet the required conditions.

### 📋 Scheme Details

Each scheme provides important information such as:

* Scheme name
* Description
* Benefits
* Eligibility criteria
* Required documents
* Application procedure
* Relevant information and resources

### 🗂️ Scheme Categories

Schemes can be organized into categories such as:

* Education
* Agriculture
* Healthcare
* Employment
* Women and Child Welfare
* Financial Assistance
* Housing
* Social Welfare
* Entrepreneurship

### 📚 Knowledge Sharing

The platform presents government scheme information in a structured and easy-to-understand format so users can make better use of available government benefits.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sangeetha-ms5/Easy-Access.git
```

### 2. Navigate to the Project

```bash
cd Easy-Access
```

### 3. Install Dependencies

```bash
pnpm install
```

### 4. Start the Frontend

```bash
pnpm dev
```

Open the local URL shown in the terminal to access the website.

## ⚙️ Backend Setup

Navigate to the backend folder:

```bash
cd backend
npm install
```

Create a `.env` file for your environment variables and configure your MongoDB connection.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
MONGO_DB_NAME=easyaccess
```

**Do not commit the `.env` file to GitHub.**

Start the backend:

```bash
npm run dev
```

## Backend setup

1. Install backend dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Create a `.env` file in the project root with your MongoDB connection string:
   ```bash
   PORT=5000
   MONGO_URI=mongodb://127.0.0.1:27017
   MONGO_DB_NAME=easyaccess
   ```
3. Start the backend:
   ```bash
   cd backend
   npm run dev
   ```
